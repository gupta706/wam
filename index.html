01 · From statistical forecasting to foundation models

Each era changes what the model is allowed to learn — from explicit coefficients to reusable pretrained temporal priors.

1950s–70s

AR / MA

Coefficients describe temporal dependence.

1970s–2000s

ARIMA

Trend, stationarity and noise.

1980s–2000s

State Space

Hidden state + observations.

2010s

RNN / LSTM

Nonlinear memory.

2017–22

Transformers

Attention over context.

2023+

TSFMs

Transferable temporal priors.

Explicit dependence

xₜ = c + φ₁xₜ₋₁ + ··· + φₚxₜ₋ₚ + εₜ

The key transition is representational. Classical models specify the dependency structure; neural sequence models learn it; foundation models attempt to learn reusable structure across many series and domains.

03 · The foundation-model pipeline

Equation → representation → model state → probabilistic forecast.

02PatchN ≈ T/P
03Embedℝᴾ → ℝᵈ
04AttendQ,K,V
05Representhₜ

07Quantifyq₀.₁…q₀.₉
What changes with a foundation model? The model is pretrained across many temporal patterns before it sees your task. At inference, the context is used to retrieve and transform learned temporal structure rather than learning every relationship from scratch.

04 · The latest model landscape

Three current families, three different routes to reusable temporal forecasting. Capabilities below are based on the official sources available in September 2026.

GOOGLE RESEARCH · 202601

TimesFM 3.0

Decoder-only foundation model with native univariate and multivariate forecasting plus past-only and past-and-future covariate support.

pθ(xT+1:T+H | x1:T, c)
AMAZON SCIENCE · 2025+02

Chronos-2

Extends the Chronos tokenization idea to zero-shot univariate, multivariate and covariate-informed forecasting.

values → tokens → Transformer → samples
SALESFORCE · 202503

Moirai 2.0

Moves to a decoder-only Transformer and expands pretraining data for faster, smaller and more accurate general forecasting.

context → decoder → p(future)

TimesFM 3.0 · what changed

  • Native multivariate + univariate forecasting.
  • Past-only and past-and-future covariates.
  • Zero-shot generalist forecasting is the central usage pattern.
  • Official repository reports the 3.0 checkpoint and notes its current pretrained-weight license is non-commercial/non-production.

How to use it in the lab

  1. Choose a bundled dataset.
  2. Select context and horizon.
  3. Decide whether the problem is uni- or multivariate.
  4. Add covariates only when they exist at inference time.
  5. Compare zero-shot output with a simple baseline.
  6. Inspect quantiles, errors and failure modes.

08 · The WAM bridge — from observed time series to latent dynamics

Use controlled nonlinear systems as a scientific laboratory for asking whether temporal representations recover meaningful low-dimensional structure.

MULTI-POPULATION KURAMOTO

Collective phase dynamics

dθᵢ/dt = ωᵢ + Σⱼ Kᵢⱼ sin(θⱼ − θᵢ)

200 coupled oscillators, five strongly coupled internal communities and weaker inter-community coupling. The intended effective manifold is low-dimensional relative to the raw state.

STUART–LANDAU

Nonlinear oscillatory state

dzᵢ/dt = (λᵢ+iωᵢ)zᵢ − |zᵢ|²zᵢ + ΣⱼKᵢⱼ(zⱼ−zᵢ)

200 complex nonlinear oscillators near a Hopf regime, organized into seven clusters. Observe amplitude, phase and cluster structure before forecasting.

KURAMOTO–SIVASHINSKY

Spatiotemporal chaos

uₜ + uuₓ + uₓₓ + uₓₓₓₓ = 0

A stiff chaotic PDE represented spectrally on a 200-point spatial grid. The lab connects complex trajectories to representation learning and forecasting.

Select a system to animate its trajectory.
THE KAIROS RESEARCH QUESTION

Can a foundation model learn the structure of time — not merely the next value?

Forecasting is the visible output. The deeper research object is the representation: which temporal dependencies become reusable, how uncertainty is represented, how covariates alter the learned state, and whether the same machinery can bridge real-world time series with controlled nonlinear dynamics.

DATA→REPRESENTATION→LATENT STATE→DYNAMICS→FORECAST→DECISION
